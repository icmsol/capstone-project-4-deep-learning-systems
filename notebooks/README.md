# Notebooks

The fully executed and authoritative submission notebook is stored at the repository root:

- [`../deep_learning.ipynb`](../deep_learning.ipynb)

This directory intentionally does not contain a duplicate `.ipynb` file. Keeping one authoritative notebook prevents reviewers from opening an outdated or unexecuted copy and ensures that the Open in Colab badge, documented outputs, and submitted results all refer to the same artifact.

The root notebook contains the complete workflow: source and data-quality audit, contract-grouped splitting, training-only vocabulary construction, custom Transformer implementation, pilot validation, controlled 15-epoch comparison, final test evaluation, error analysis, dependency snapshot generation, and the required five-sentence summary.
